# 自定义提示词模板 · 放这里

> **你是用户**：把你自己的提示词（那个你一直在用的"教模型怎么写分镜"的长提示词）
> **整个文件丢进这个文件夹**，然后跟 AI 说一声「**用我的模板**」就行。

---

## 怎么用（两步）

### 1. 把你的模板丢进来

```
prompts/_自定义模板/我的模板.md      ← 文件名随便起，.md / .txt 都行
```

### 2. 告诉 AI

```
我用自定义模板，模板在 prompts/_自定义模板/我的模板.md
```

AI 会**先做一次「最小改造」**（只动外壳，正文一个字不改），改造完给你过目，
你点头了才正式用它写词。

---

## ⚠ 改造会动什么、不会动什么

| | 内容 | 会改吗 |
|---|---|---|
| ✅ **会改** | ① **分包标记** —— 每个分镜组用 `&&start` … `&&end` 包起来 | 改成我们的格式 |
| ✅ **会改** | ② **资产引用写法** —— 统一成 `pn1,资产名=@`（图片）/ `vm1,资产名=@`（音色） | 统一写法 |
| ✅ **会改** | ③ **开头结构** —— 补/归一【基础信息】【统一风格模块】【强制声明】【资产盘点】四段 | 只补壳 |
| ⛔ **不会改** | 字段名 / 字段顺序 / 模块划分 / **正文文体** / 哪块能省 | **原样保留** |
| ⛔ **不会改** | 剧情 / 台词原文 / 人物设定 / 人物关系 | **一字不改** |

**判据**：改造完，**你还认得出这是你的模板** —— 认不出就是改多了。

> 完整规则（含改造清单、前后对照示例、三条红线）→ **`../提示词最小改造准则.md`**

---

## 为什么只改这三样

因为后面的流程是**确定性的**，它靠这几个标记干活：

| 标记 | 谁在用 | 用途 |
|---|---|---|
| `&&start` / `&&end` | 作业单生成 / 提交脚本 | **切组** —— 一个块 = 一个分镜组 = 一条提交 |
| `分镜组ID：X` | 任务台账 / 下载归档 | **对账锚点** —— 提交完靠它把成片对回分镜组 |
| `pn1,名=@` / `vm1,名=@` | mention 重建 / 上传脚本 | **绑定资产** —— 决定第几张图配哪个角色 |

这三样是**接口**；**正文怎么写，完全是你模板的事**。

---

## 放进来之后

- 改造稿会另存一份（`_已改造_` 前缀），**你的原稿不动**；
- 之后每次写词都用**改造稿**，直到你换模板；
- 想换回内置的自己人模板 ⇒ 直接说「**用回自己人**」。
