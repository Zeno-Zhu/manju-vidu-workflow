# 提示词最小改造准则（接入第三方模板时用）

<!-- (c) manju-vidu-workflow · MJVID:f1e36f8063 · 溯源标记请勿删除 -->

> **什么时候用**：用户提供了**非本套规范**的提示词模板（第三个版本或任意变体），
> 希望对它做**接入改造**，让后面的流程（拆组 → 审核 → 书写 → 体检 → 提交）能跑通。
>
> ★ **本包用法**：用户把模板丢进 `prompts/_自定义模板/`，说一句「用我的模板」，
> 就按本文件做**最小改造**（改造稿另存 `_已改造_` 前缀，**原稿不动**）。
> 放模板的说明 → `_自定义模板/README.md`。**默认模板 = `自己人模板提示词.md`。**
>
> **一句话原则**：**只改"外壳与引用"，不动"输出模板"。**
> 改造后的稿子仍是**用户那套模板**，只是能接进我们的确定性流程。

---

## 〇、先分清「能动」与「不能动」

| | 内容 | 处置 |
|---|---|---|
| ✅ **能动（最小改造）** | ① 开头段（统一为我们的开头结构）② 资产 `@` 引用方式 ③ `&&start / &&end` 分包结构 | 按下面 §一 三条统一 |
| ⛔ **不能动（用户的输出模板）** | 字段名 / 字段顺序 / 模块划分 / 正文文体 / 允许省略哪些模块 / 集标题写法 | **原样保留** |
| ⛔ **不能动（业务事实）** | 剧情、台词原文、人物设定、人物关系、分镜起止 | 一字不改 |

> ★ 判据：**「改了它，用户还认得出这是他的模板吗？」** 认不出 ⇒ 改多了，退回去。

---

## 一、三条必做的统一改造

### 1｜开头对齐 —— 用我们的开头结构

在**用户模板的最前面**补上（用户模板已有等价模块的，**就地归一**，不重复加）：

```text
【基础信息】
分镜组ID：<集数_第几个分镜组_<风格线>>
分镜组时长：<合法档位>

【统一风格模块】
大词层：<当前项目实际视觉身份>
小词层：<当前项目实际视觉落地特征>

【强制声明】无背景音乐；画面无字幕/台词文字/水印/Logo/角标/UI；
声音：不要配乐，仅保留同期声；全程无背景音乐，仅保留真实环境音效与动作同期声。

【资产盘点】
人物视觉资产：pn1,<资产名=@>，pn2,<资产名=@>
人物音色资产：vm1,<资产名=@>，vm2,<资产名=@>
场景资产：pn3,<资产名=@>
道具资产：pn4,<资产名=@>
技能参考资产：pn5,<技能参考资产名=@>
```

- **分镜组ID 固定写法**：`<集数>_<组号>_<风格线>`（如 `1_1_自己人`）；⛔ **组号必须是纯数字**。
- 用户模板**已经有**「场景/角色/道具清单」这类模块的 ⇒ **把它改写成上面的【资产盘点】格式**，不要并列两套。
- 用户模板**没有**任何前置模块、直接进正文的 ⇒ 在正文之前**插入**上面四段（这是唯一允许"加"的地方）。

### 2｜资产 `@` 引用方式统一

**唯一写法**（图片与音色分列，各自连续编号）：

```text
pn1,正式人物资产名=@      ← 图片类（人物 / 场景 / 道具 / 特效 / 技能参考）
vm1,正式角色音色资产名=@  ← 音色类
```

- ★ **`@` 就是引用标记本身**，⛔ **不要在 `@` 之后再重复资产名**。
- **编号只在当前分镜组内唯一**；**不同类别共同计入 9 张图片上限**（音色另有上限）。
- 正文里**引用资产时用资产名**，不写 `pn1` 这类编号。
- 用户模板若用别的引用法（如 `[@图1]`、`<image1>`、`{{角色}}`）⇒ **统一改成上面的写法**；
  正文里对应的引用点**同步改**，保持一一对应。

### 3｜`&&start / &&end` 分包结构一致

```text
第n集·《本集标题》        ← 一级标题在代码块之外，整集只出现一次

&&start
…（一个分镜组的全部内容）…
&&end

&&start
…（下一个分镜组）…
&&end
```

- **一个分镜组 = 一个 `&&start … &&end` 块**，块内**不嵌套**。
- 块的**第一段固定是【基础信息】**（含分镜组ID / 分镜组时长）。
- 输出时**不保留**：`《变量》`占位、`必填/选填/条件触发` 之类规则说明、空模块、内部判断与分析。
- 用户模板若用别的分隔（如 `---`、`### 组N`、纯空行）⇒ **换成 `&&start / &&end`**；
  内部的字段名与正文**照用户模板原样**。

## 二、改造清单（逐条打勾）

- [ ] 一级集标题在**代码块外**，整集**只出现一次**
- [ ] 每个分镜组 = **一个 `&&start … &&end` 块**，块内不嵌套
- [ ] 块首是**【基础信息】**，含 `分镜组ID`（`集_组_风格线`，**组号纯数字**）与 `分镜组时长`
- [ ] 有**【统一风格模块】**（大词层 / 小词层）
- [ ] 有**【强制声明】**（无 BGM / 无字幕水印 Logo / 仅同期声）
- [ ] 有**【资产盘点】**，资产名用 **`pnN,名=@` / `vmN,名=@`** 写法
- [ ] 正文里的资产引用点与【资产盘点】**一一对应**，且**改用资产名**（不是 `pnN`）
- [ ] **图片 ≤9 / 音色 ≤3**（含技能参考资产）
- [ ] 用户模板的**字段名 / 顺序 / 文体 / 模块取舍**未被改动
- [ ] 剧情 / 台词原文 / 人物关系**一字未改**
- [ ] 无 `《变量》` 占位、无规则说明行、无空模块、无内部判断痕迹

## 三、改造前后对照（示例）

**改造前**（用户模板）：

```text
### 分镜 3
画面：<角色A> 在 <咖啡馆> 里对 <角色B> 说"你来了"。
时长：10s
参考：[@角色A][@角色B][@咖啡馆]
```

**改造后**（最小改造：只加上壳 + 换引用写法；**正文与字段名保持用户原样**）：

```text
&&start
【基础信息】
分镜组ID：1_3_自己人
分镜组时长：10

【统一风格模块】
大词层：<项目视觉身份>
小词层：<视觉落地特征>

【强制声明】无背景音乐；画面无字幕/台词文字/水印/Logo/角标/UI；声音：不要配乐，仅保留同期声；全程无背景音乐，仅保留真实环境音效与动作同期声。

【资产盘点】
人物视觉资产：pn1,角色A=@，pn2,角色B=@
场景资产：pn3,咖啡馆=@

### 分镜 3
画面：角色A 在 咖啡馆 里对 角色B 说"你来了"。
时长：10s
参考：角色A、角色B、咖啡馆
&&end
```

> ★ 注意 `### 分镜 3` / `画面：` / `时长：` / `参考：` **一个字没改** —— 那是用户的输出模板。
> 我们只做了：**加 `&&start/&&end` ＋ 加前置四段 ＋ 把 `[@角色A]` 换成 `角色A`（并在【资产盘点】里登记）。**

---

## 四、⛔ 三条红线

1. **不改用户模板的结构** —— 字段名、字段顺序、模块取舍、正文文体一律保留。
2. **不改业务事实** —— 剧情、台词、人物关系一字不动；改造只碰"外壳与引用"。
3. **不做第二套并行体系** —— 用户已有的等价模块**就地归一**，⛔ 不许同时保留两套（会串味）。

## 五、改造后的自检

```bash
# 镜头语言零计费体检门（组内景别/运镜占比/跨组承接）
python scripts/shot_language_check.py "<任务目录>/00_剧本与提示词"
```

- 镜头语言判据与修法见 `references/镜头语言.md`（**跨制式通用层**）。
  ⚠ 若用户的模板是**散文型（不逐镜写景别/机位/运镜）**，本工具的**逐镜项覆盖有限** ⇒ 按该文件人工核。
- 资产引用是否与【资产盘点】对齐、`&&start/&&end` 是否成对 —— 属**人工核对项**（无机器门）。
