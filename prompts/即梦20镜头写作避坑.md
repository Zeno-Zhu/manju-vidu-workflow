# 即梦20（标准版）镜头写作避坑清单

<!-- (c) manju-vidu-workflow · MJVID:f403398906 · 溯源标记请勿删除 -->

> **来源**：2026-10-07，同一份《即梦20标准提示词》规范写下 53 组提示词，成片"镜头死了"，
> 抽帧+统计后归因得到这份清单。
> **用法**：写完一组正文，拿下面 9 条过一遍。**这不是新规则，是把规范里本来就在、
> 但写成"条件触发"因而被默认跳过的条款，改回"默认动作"。**
> 适用渠道：`通用提示词.txt`（渠道通用底座）派生出的全部渠道稿，即
> `即梦20`（器灵 / libtv / vidu）/ `即梦2.5 标准版`（云鲸）/ `即梦2.5 简单版`。
> 这些渠道跑的是同一套镜头规范，**同一个坑**。
> 例外：`即梦2.5 自己人版` 刻意把镜头调度权交给模型（见 `即梦25自己人.txt` L345-346），
> 第 1/2/3 条不适用，但**第 4/6/7/8/9 条仍然适用**（它用【首尾定点】替代逐△机位）。
> `H3多参提示词.md` 语法独立，但第 4–9 条方法论可直接迁移。

## 一句话根因

规范《镜头单元与△使用规则》第六节写的是：

> 「六、运镜描述要求 —— 同一个△中存在**明显运镜、主体转换或画面阶段变化时**，根据实际需要
> 写清摄影机围绕谁……**简单固定镜头或短距离自然调整无需机械填写全部摄影参数**。」

"条件触发 + 简单镜头可省"被写稿时读成了「**不写就是交给模型自由发挥**」。
实测后果：

| 项 | vidu 53 组 / 130 △（改写前） | 云鲸 24 组 / 119 △（对照组） |
|---|---|---|
| △ 里写了运镜 | **3 / 130 ≈ 2%** | 3 / 119 ≈ 3% |
| 景别分布 | 近景 81 / 中景 49 / 中近景 16 / 全景 3 | 近景 72 / 中景 47 / 中近景 14 / 全景 3 |
| 全篇出现「特写/大特写/远景/俯拍/仰拍/过肩/主观」 | **0 处** | 0 处 |
| 单 △ 组 | 9 / 53（承载 4–7 句台词） | 0 |

**模型看到的就是「一个中景，把 5 句台词念完」。** 不是平台的问题，也不是重切造成的
（两版 △ 密度一致：vidu 0.163/s，云鲸 0.165/s），是**稿子没给镜头语言**。

## 10 条（逐条对照）

### 1｜每个 △ 开头必须是「景别 + 机位/角度」，不只是景别
```
✗ △中景。
✓ △中景，机位在门槛内侧、略仰，固定。
✓ △近景，机位切到二丫正面偏轴约二十五度。
```
只写景别，模型会自己挑一个机位并且**整组不换**。

### 2｜「固定」也要显式写出来
不写运镜 ≠ 固定机位 —— 模型会随机漂。固定就写"机位固定不动"；
要动就写清方向与落点。**沉默不是指令。**

### 3｜运镜写四件事：围绕谁 / 从哪里观察 / 往什么方向动 / 落在什么画面重点
```
✗ 镜头变化、画面转向、镜头来到        （缺主体、缺方向，等于没写）
✓ 机位随他转身向厨房方向横摇跟移，落点压到碗沿的两个煮鸡蛋上
✓ 机位退到餐桌斜侧四十五度、带两人半身，随晓敏坐回椅子时轻微下压
```
规范原文点名禁止的正是这三个模糊表达。

### 4｜一组之内景别必须有层级变化
实测 53 组里近景+中景占 98%，**没有一次跳变**。
最低要求：**≥3 个 △ 的组，至少出现一次"近→远"或"远→近"的跳变**
（例如：中景双人 → 近景单人 → 特写道具）。

### 5｜切点落在三种地方，不要落在句号上
① **说话人切换且需要新的观看关系** → 正反打 / 过肩
② **情绪转折** → 切到反应
③ **关键物件进入** → 切到物件

反过来说：同一观看关系里的连续短对答**不必**每句一切 —— 那才是规范禁止的"机械拆碎"。
判据是"观众需不需要一个新的观看关系"，不是"换人说话了没有"。

### 6｜特写按需，不按组
只给四种落点：
- **关键道具**（鸡蛋、雪花膏铁盒、碗边两个煮鸡蛋）
- **情绪转折落点**（秀兰听见"二丫"两个字，手停在半空）
- **动作接触点**（鸡蛋从一只手交到另一只手）
- **口播/商品落点**（把三盒举到镜头前）

本次 53 组只给了 **8 处**。
```
✗ 每组都安排特写        ✗ 每句台词都切近景
```

### 7｜单 △ 组是高危信号
一个 △ 承载 4–7 句台词 = 模型只能用**一个机位**把台词念完。
本项目 9 个单 △ 组（`1_3` `2_1` `2_2` `4_2` `4_3` `5_1` `12_3` `12_7` `12_8`）
恰好全是"台词最多、镜头最死"的组。

**经验线：台词 ≥4 句就该至少 3 个 △；≥6 句至少 4 个 △。**

### 8｜首镜承接上一组末镜
同事件相邻分镜组，首镜**承接上一组末镜**，不要统一从远景 / 全景 / 推镜开场。
上一组落在近景，本组可以：继续该人物 → 进入其近景/特写 → 切对方反应 → 切动作对象或关键物件 →
换合理角度继续当前行为。**重新建立空间**只在真的换了空间/人物关系重组/新人物进入时才用。

### 9｜每组定一个峰值 △，强度不平均分配（2026-10-07 新增）

借自"同一叙事拍只允许一个主载体"：**每组动笔前先定一个峰值 △（本组的情绪峰或信息峰），
把最强的景别跳变、运镜幅度和特写留给它**，其余 △ 承铺垫、承接或反应功能，不与峰值抢强度。

- 峰值通常落在：情绪转折落点、关键物件进入、关系变化成立、口播商品落点
  （与条 6 的特写落点重合是正常的，峰值镜往往就是全组唯一的大跳变）；
- 峰值之外的 △ 用更平的机位与景别，**不是每组每个 △ 都要强**——
  全组平均用力 = 拼起来全是强度 = 观众看不出哪里是重点；
- **景别自检问句**：关键 △（峰值镜 / 转场镜 / 关系变化镜）动笔前自问
  **"这个景别/机位换成相邻一档会失去什么？"**——答得出失去什么，才保留这个选择；
  答不出理由，退回该叙事功能的默认档（说内容＝中景带听者，说关系＝双人同框，交代＝全景）。

### 10｜空间站位与跨组继承（2026-10-10 新增）

存在人物互动 / 移动 / 多人同场 / 关键物件交互的组，正文里必须交代**空间站位**：
谁在哪、站还是坐、离谁多远、拿着什么、是否接触、正在往哪走。

跨组时必须**继承上一组已经成立的真实状态**。三条最容易搞错：

- **真实空间 ≠ 画面左右**：「餐桌靠窗侧」是空间事实（跨机位继承）；
  「frame left」只是当前机位的屏幕位置，**换机位就变**。
- **身体状态跨组继承**：上一组结束时坐着，本组就从坐着开始 ——
  ⛔ 不因为换了提示词就回到中性姿势。
- **没入镜 ≠ 离场**：只有剧情明确离开才从站位里移除；没入镜的人**仍在场**，可以被提到、可以被切回去。

站位只写「**进入本组时已成立**」的状态；组内新发生的起身 / 移动 / 跌倒写进对应 △。
单人近景、空间无歧义时可以缩到一句。**不要写成场面调度说明书**。

> ⚠ 本条**没有机器门**（`shot_language_check.py` 查的是构图/景别的形式重复，查不了站位语义）⇒
> **写完人工核一遍**：本组开头写的站位，是不是上一组结束时的那个状态。

## 自检（可脚本化）

- [ ] 每个 △ 都含**景别词 + 机位/角度词**
- [ ] 每个 △ **三项写全**：景别 ＋ 机位/角度 ＋ **运镜状态**（**固定也要显式写**）
      —— 「不写运镜」≠「固定机位」，**固定机位是合法且完整的镜头设计，不是缺少运镜**
- [ ] 特写 **5–10 处**（不是 0，也不是每组都有）
- [ ] 没有"台词 ≥3 句却只有 1 个 △"的组
- [ ] 特写只出现在道具 / 情绪落点 / 接触点 / 商品口播
- [ ] 台词行与 `<>` **一字未改**（台词零容错红线）
- [ ] 每个 △ **有效时长 ≥1.2s**：`△数 × 1.2 ≤ 声明时长`
- [ ] 每组能**指出峰值 △** 是哪一个；峰值之外的 △ 没有与之抢强度的运镜/特写
- [ ] 关键 △ 能答出"**为什么是这个景别**"（答不出＝退默认档）
- [ ] **每组首镜**与上一组**末镜**构成成立的切点（没有无理由的远景/推镜开场）—— 条 8
- [ ] **本组开头写的站位/身体状态**，就是上一组结束时的那个状态 —— 条 10

|---|---|

| 条 9 峰值 △ / 强度不平均 | **告警 G、H**：跨组高频构图套件、相邻组连续同首镜 |
| 条 5 切点落三种地方 | ⛔ **无机器门**（看的是台词在 △ 内的位置） |
| 条 8 首镜承接上一组末镜 | ⛔ **无机器门**（`H` 只查"相邻组连续同首镜"的形式重复，查不了"是不是无理由远景开场"）**必须人工核** |
| 条 10 空间站位与跨组继承 | ⛔ **无机器门** **必须人工核** |

> ⚠️ 机器只能查**形式**（写没写、密不密、重不重复）；**峰值是否选对、景别是否合理、
> 组首是不是无理由远景开场、站位有没有跨组继承** —— 这四条仍须人工按条 5 / 8 / 9 / 10 判。

  `manju-creation/references/镜头语言.md`（2026-10-11 上浮：一镜三件套 / **运镜是戏剧任务的函数（⛔ 不设配额）** /
  每个运镜交代落点 / 峰值镜头 / 跨组承接 / **反回声三类**）。**写词先过通用层，再按本文件落地。**
  起因：H3 制式此前读不到这套方法论 ⇒ 龙须面44 全片 124 镜里 68 镜在推、EP02/EP03 固定机位为 0。
- 本条**不新增台词、不改台词、不改剧情与人物关系** —— 只改 `△` 行。

  若某渠道需要"移除自由运镜"，在**生成侧**做确定性替换（见 `manju-vidu` 的 `fit_tail`）。
