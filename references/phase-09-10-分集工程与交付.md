## Phase 9｜分集工程

**① 进入 / 跳过条件**
- 必须做：该集 **Phase 7 已有成片**（否则素材清单里 `videos` 为空，产出没意义）。
- ⛔ 跳过：`00_剧本与提示词/EPxx/素材清单.json` 已存在且成片没变。（★ 默认**不做剪映**，不再把草稿配置当跳过判据。）
- ⚠ **成片有增补后要重跑**（清单是快照，不会自动增量）。

**② 输入**

| 类别 | 路径 |
|---|---|
| 输入 | `02_分集工程/EPxx/视频/*.mp4`（Phase 7 成片） |
| 输入 | `01_资产库/音色/*`（用户自备音色，可选） |
| 输入 | `00_剧本与提示词/EPxx/分镜组/*`（分镜表与统一制作规划）★ 2026-10-03 起信息类文件归此 |
| 外部工具 | ~~剪映草稿导出器~~（★ 默认**不做剪映草稿**，仅用户点名时启用） |

**③ 做什么**

```bash
python main.py run --project "<项目名>" --step 9.1      # ★ 默认只跑 9.1；9.2（剪映草稿）默认跳过
```

| 步骤 | 做什么 | 关键点 |
|---|---|---|
| 9.1 | **每集素材清单** | 扫 `EPxx/视频`、`00_剧本与提示词/EPxx/分镜组`、`01_资产库/音色`，出 `00_剧本与提示词/EPxx/素材清单.json` |
| ~~9.2 剪映草稿~~ | ★ **默认不跑**（用户 2026-10-04 定）。仅点名要求时执行：① 复制 `EPxx/视频/*.mp4` 到中间的 `_剪映草稿/草稿素材/EPxx/` ② 写 `剪映草稿配置.json`（1080×1920 @30fps）③ 调 `export_draft.py` |

> ★ **9.2 是复制不是移动** —— 原成片留在 `EPxx/视频/`，草稿素材是旁路副本。（★ 默认口径下 9.2 不跑）
> ★ 找不到导出器时**不报错**，只在结果里标 `tool: 未找到`，配置照常产出。

> ★★★★ **前置条件：Phase 7 的出片台账 ≠ 框架 registry（2026-10-03 踩到）**
> `h3_batch_all.py` 只写自己的 `_出片记录/任务台账.json`，**不往 `产物清单.json` 登记 video 节点**；
> 而 `step_10.run_10_2` 靠 `registry.list_by_type("video")` 收集成片。
> ⇒ **必须先桥接登记**，否则交付包里**一个视频都没有** —— 而且 `10.2` 只报 `count: 0`、**不报错**，极易漏掉。
> 做法：`python _p9_register_videos.py "<项目目录>" --apply`
> （扫 `02_分集工程/EPxx/视频/*.mp4` → `registry.upsert("video", 组号, status="completed", output_files=[绝对路径])`；
> 自动备份 `产物清单.json` 为 `.bak_prevideo`）

> ★ 还有一步一次性迁移：Phase 7 成片默认落在 `EPxx/*.mp4`，
> 而本阶段要求 `EPxx/视频/*.mp4` ⇒ 先搬（只搬不删）。

**④ 产出**

| 产物 | 路径 |
|---|---|
| 素材清单 | ★ **`00_剧本与提示词/EPxx/素材清单.json`**（按集归档） |
| 分镜表 | ★ **`00_剧本与提示词/EPxx/分镜组/`** |
| ~~剪映草稿配置 / 草稿素材 / 剪映草稿~~ | ★ **默认不产出**（不做剪映草稿）。点名要求时才落在 `02_分集工程/_剪映草稿/`（中间件；导出器按 `--draft-name` 建目录） |

> ★★★★ **文件结构红线（2026-10-03 用户定）**：**`02_分集工程/` 只放干净剪辑素材**
> —— 即 `EPxx/视频/*.mp4`（成片）＋ `EPxx/_废案_xxx/`（变体）。
> **一切信息类文件**（素材清单、分镜表）归 **`00_剧本与提示词/EPxx/`**（按集归档）；
> **重复副本与配置**（草稿素材、剪映配置）归 **`02_分集工程/_剪映草稿/`**（`_` 前缀＝中间件）。
> 理由：在分集工程里翻找素材时不被非素材文件干扰。迁移工具：`_出片记录/migrate_layout.py`。

- 节点登记：`draft`，`node_id = 集数`。

**⑤ 闸门**
- 无独立检查点。★ **人工验收点**（★ 默认口径下**不做**——只在真出了剪映草稿时才验收）：
  打开剪映草稿，按**场号顺序**检查拼接顺序
  （成片靠组号里的集号自动落到 `EP01…EPxx`，顺序错了多半是组号错）。

## Phase 10｜最终交付

**① 进入 / 跳过条件**
- 必须做：Phase 9 已出素材清单。
- ⛔ 跳过：`04_最终交付/` 已存在。（★ 默认**不做 CP-5 确认**。）

**② 输入**：产物登记表（`registry`）全部节点 + `02_分集工程/` 成片。

**③ 做什么**

```bash
python main.py run --project "<项目名>" --step 10.1-10.3
```

| 步骤 | 做什么 |
|---|---|
| 10.1 | **交付清单**：汇总登记表全部节点 + 状态汇总（★ 默认**不生成 CP-5 报告**） |
| 10.2 | **交付包整理**：收集无水印视频与成品文件到 `04_最终交付/` |
| 10.3 | **交付摘要报告** |

**④ 产出**

| 产物 | 路径 |
|---|---|
| 交付清单 | `04_最终交付/交付清单.json` |
| ~~CP-5 报告~~ | ★ **默认不生成** |
| 交付包 | `04_最终交付/`（成片 + 成品文件） |
| 交付摘要 | `04_最终交付/`（10.3） |
| ~~成片合集 / 整片拼接~~ | ★ **默认不产出**（2026-10-08 用户定）—— 平时交付物**就是逐组成片**；只有用户点名要求剪辑（或显式让调用剪辑 skill）时才做，⛔ 不自行 ffmpeg 拼接、不塞进 `04_最终交付/` |

**⑤ 闸门**

| 门 | 时机 | 类型 | 谁批 | 说明 |
|---|---|---|---|---|
| ~~CP-5 交付确认~~ | 10.1 之后 | 报告（非 gate） | 用户 | ★ **默认不做** —— 交付清单照出，人工确认这一步取消 |

> ★ **交付前跑一次产物核对**（Phase 7 第⑤步）—— 交付清单只统计"有没有产物"。
> ⚠️ 按 2026-10-04 默认口径，**抽帧 / 音频核验默认不做** ⇒ 产物"演得对不对"由用户在播放器/剪映里自行验看。
