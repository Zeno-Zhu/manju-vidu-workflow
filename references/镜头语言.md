本文件即为此层；四份制式各自只保留「词表 + 写法差异」。

## 二、一镜三件套（硬要求）

每个镜头必须同时写清 **① 景别 ② 机位/角度 ③ 运镜**。

- 只写景别 = 把机位交给模型随机决定，且**整组不换**；
- **固定也要显式声明**（`static camera` / 机位固定）—— **沉默不是指令**；
- ⛔ 禁写「镜头变化」「画面转向」「镜头来到」这类缺主体、缺方向的模糊表达（规范点名禁止）。

---

## 三、运镜是戏剧任务的函数（★ 不设配额）

★ **所有运镜与拍摄角度都携带情绪，都要按剧情与上下分镜组来选** ——
**没有「该多用 / 该少用」的固定比例**，本文件也不规定百分比。

| 戏剧任务 | 常用选择 | 作用 |
|---|---|---|
| 集中注意、压缩空间、强化当前信息 | 推 | 把观众压向一个点 |
| 释放空间、展示关系、放大距离 | 拉 | 把关系交出来 |
| 连接人物与空间信息 | 摇 | 一镜之内交代"谁在哪、谁跟谁" |
| 维持移动连续、表现层次与遮挡 | 移 / 跟 | 让动作可读 |
| 改变空间尺度与地位感 | 升降 | 权力与体量 |
| 强化人物关系或主导权变化 | 环绕（有限角度） | 关系本身就是戏点 |
| **表现不安、犹疑、压迫、亲密、呼吸感** | **微推 / 手持 / 轻微抖动** | ★ **有效工具，按情绪用 —— 不是禁品** |
| 任何无特殊需求处 | 固定 | **基线**，不是"平淡档"、不是"没设计" |

★ 关键区分：**微推本身没错，错的是「无情绪依据地逐镜复用同一句微推」。**

---

## 四、每个运镜必须交代落点

写运镜时写清四件事：**围绕谁 / 从哪里观察 / 往什么方向动 / 落在什么画面重点**。

- 答不出"**服务什么画面重点**" ⇒ 退回 §三 该戏剧任务对应的选择，或直接用固定；
- 组内多镜同向运动（如连推）只有在**同一情绪推进过程**里才成立，且不得逐镜复用同一句式。

---

## 五、峰值镜头（每组一处，不平均用力）

- 每组动笔前先在内部定**一个峰值 Shot**（本组的情绪峰或信息峰）；
- **最强的景别跳变、运镜幅度、特写留给它**，其余镜头承铺垫 / 承接 / 反应功能；
- ⛔ **不允许一组内每个镜头平均用力**；⛔ 也不允许把最强镜头语言浪费在非峰值位置；
- 峰值常落在：情绪转折落点、关键物件进入、关系变化成立、口播 / 商品落点。
- 自检问句：关键 Shot 的景别/机位「**换成相邻一档会失去什么？**」
  答不出 ⇒ 退回该叙事功能的默认档（说内容＝中景带听者；说关系＝双人同框 / 越肩；交代空间＝全景）。

---

## 六、跨组：承接，不是重启

同一连续事件的**相邻两组**：

- **组首承接上一组末镜** —— **景别与运镜同时承接**；⛔ 不要统一用远景 / 全景 / 建立镜 / 推镜开场；
- ⛔ 组首**不要重复上一组的运镜**（上一组末镜在推、本组首镜接着推，观感就是一条停不下来的长镜）；
- **组首景别由上一组末镜推导**：末镜远景 → 中景/近景｜末镜中景 → 近景/特写/反打/越肩/双人｜
  末镜近景 → 同景别续接或切听者｜末镜双人 → 单人；
- **允许由远推近，禁止无理由由近拉远**；
- 180° 轴线、朝向、视线、持物手**跨组不变**；
- **组尾**收在稳定、静态、信息完整的画面（⛔ 不收缩在大幅运动、甩镜、极端角度或过度虚焦中）；
- 只有**真实换场 / 换时间 / 转场 / 闪回**时才重新交代空间。

---

## 七、反回声（机器门查的就是这一节）

**不是「少用推镜」，是「不要重复」。** 三种回声都要避免：

1. **组内**：连续 ≥3 个镜头同「景别 + 运镜」；
2. **跨组**：相邻组**首镜**连续同「景别 + 运镜」——
   **含固定机位**（连续三组都以固定中景开场，同样观感上是"每组一个样"）；
3. **全季**：同一「景别 + 运镜」套件高频复现 ——
   - ★ **只算运动类运镜**：**固定机位是基线，重复不构成回声**；
   - ★ 判据为**双条件**：次数 ≥ `--suite-min`（默认 4）**且**占全季镜数 ≥ `--suite-pct`（默认 15%），
     避免小项目漏报 / 大项目误报。

★★ **机器门 ≠ 创作配额**：工具只回答"**有没有重复**"，**不规定"该用多少推镜"**；
**选什么运镜永远由剧情与上下分镜组决定**（§三）。

⇒ 机器判据 = `tools/shot_language_check.py`；
   本文件负责"**怎么选**"。**两者都要过**。

★ **修连排的正确姿势：景别与运镜一起错开**（2026-10-12 实测）

发现「相邻组首镜连续 3 组同套件」时，⛔ **只把运镜换掉是换汤不换药**。
实测：`3_24/3_25/3_26` 原本都是 `medium close-up + pushes in`，
若只改成 `medium close-up + locked-off` —— 套件**照样三连排**，告警不会消。
**必须按承接逻辑让景别也分档**（中景 / 双人 / 近景 各一），才真正破掉回声。

同理，替换运镜时要**检查新写法是否与邻组撞车**：
把 6 个组都改成同一个固定写法，就只是把"推镜同质化"换成"静机同质化"。

⇒ **改完必须回跑工具**，看「相邻组首镜连续同景别」那一节是否真的少了一行。

★ **三态退出码（2026-10-11，外部评审后定）**：
- **0 = PASS**（无阻断）—— **告警只呈现证据，不阻断出片**；
- **2 = BLOCK**（仅结构性错误：**没写景别 / 没写运镜状态**这类确定性缺失）；
- **1 = 仅 `--strict` 下**（把告警也当门用，适合交付前清场）。

⛔ **判据 C（运镜/机位覆盖率 ≥60%）已删除** —— 它表面是"下限门"，
**本质是一条创作配额**：一部戏若本就该全用固定机位，它永远过不了门。
覆盖率降级为**只报告的参考值**；同时**新增 A2**：每镜必须写**运镜状态**——
「不写运镜」≠「固定机位」，固定也要写 `static camera` / 机位固定。
（**固定机位的连排**同样不告警：固定是基线，连续用同一种固定开场 ≠ 模板化。）

## 八、词表（按制式取用，⛔ 不跨制式混读）

| 制式 | 语法 | 运镜词表 |
|---|---|---|
| **H3** | `[Shot N]` | 英文：`static camera` / `pushes in` / `pulls back` / `pans` / `tilts` / `tracks` / `dollies in` / `racks focus` / `arcs around`（**字面**） |
| **标准 / 自己人** | `△` | 中文：机位固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 环绕 |
| **打斗** | 同各自语法 | 见 `制式-打斗.md`（动作组运镜浓度更高） |

⚠ H3 词表以 `H3多参提示词.md` 为唯一权威，本表只是索引。

### ★ 固定机位必须用「词表原文」，⛔ 不自造近义写法（2026-10-12 实测踩到）

`shot_language_check.py` 的 MOVE 词表**只认这些固定写法**（H3 系）：

    static camera   ／   locked-off   ／   camera fixed

⛔ **`camera holds static`、`camera stays still`、`fixed frame` 一律不认** ——
工具会把它判成 **A2 阻断「这个镜头没写运镜状态」**。
（写作者以为自己写了固定，工具当没写；**「沉默不是指令」对工具同样成立**。）

同理，运动词也**只认字面**：`pushes in` / `pulls back` / `pans` / `tilts` / `tracks` /
`dollies in` / `racks focus` / `arcs around`。
⛔ `camera holds steady`、`drifts`、`arcs around`（拼成 `arc around`）都不认。

⇒ **改词后必须回跑 `shot_language_check.py` 看阻断段是否清零**，⛔ 不要凭「我写了固定」自证。
