## ★ 开工第一步：先探明项目现状（**别急着跑命令**）

```bash
ls "<项目根>"                    # 有没有 00_剧本与提示词 / 01_资产库 / 02_分集工程 …
ls "<项目根>/00_剧本与提示词/"    # 剧本、带时长剧本、分集，到了哪一步
```

**逐项判定，能跳就跳**：

| 探到什么 | 结论 |
|---|---|
| 项目根**已有** `00_剧本与提示词` / `01_资产库` / `02_分集工程` / `03_背景音乐` / `04_最终交付` | ★ **Phase 0 的建目录部分跳过**（用户已搭好），只补齐缺的子目录与 `项目配置.json`。★ 默认口径下 `03_背景音乐` **不产出内容**（不生成背景音乐），目录可留空 |
| 已有 `*剧本带时长*.md`（或分集里每段都带时长标注） | ★ **剧本已带时长 ⇒ 跳过 1.2** |
| 已有分集产物（`剧本拆分/第N集.md` 或根下 `第N集.txt`） | ★ **已分集 ⇒ 跳过 1.3** |
| 已有 `角色对白频次分析.md` | 跳过 1.4 |
| 全都没有 | 从 0.1 按顺序跑 |

> ⛔ **不要因为"流程里有这一步"就重跑** —— 重跑会覆盖已完成产物，
> 而 Phase 5 之后的重跑还可能**全量重编号**，作废已交付的成片名与提交单。

> ⚠ **产物路径以项目实际为准**：脚本产物落在 `00_剧本与提示词/剧本/`，
> 而**历史项目常见平铺在 `00_剧本与提示词/` 根下**（`<剧名>剧本带时长.md`、`第N集.txt`）。
> 两种都合法 —— **先看实际有什么，别搬动**。

## Phase 0｜初始化

**① 进入 / 跳过条件**
- 必须做：`项目配置.json` 不存在，或 `script_path` 没指向真实文件。
- ⛔ 跳过：项目目录已建好**且** `项目配置.json` 完好 —— 只补缺失项，不重建。

**② 输入与权威规范**
- 输入：**剧本文件**（用户给的路径）；**剧本设定**（可选）
- 规范：无（本阶段是纯落地，不产出创作内容）

**③ 做什么**

```bash
python main.py init --name "<项目名>" \
  --script  "E:/路径/<剧本>" \
  --setting "E:/路径/<剧本设定>"        # 没有设定就省略
```

拆开的 5 个原子步骤（用 `--step` 单跑时可指定）：

| 步骤 | 做什么 |
|---|---|
| 0.1 | 加载并校验全局配置（缺 `projects_root` 会报错） |
| 0.2 | 按模板建项目子目录（`os.makedirs(exist_ok=True)`，**已有的不覆盖**） |
| 0.3 | 把剧本 / 设定**复制**进 `00_剧本与提示词/剧本/` |
| 0.4 | 写入 `项目配置.json` |
| 0.5 | 初始化运行日志 |

**④ 产出**
- `项目配置.json`（含 `script_path` / `setting_path`；后续所有步骤靠它找输入）
- `00_剧本与提示词/剧本/<项目名>_剧本原文.md`、`…_剧本设定.md`
- 运行日志

**⑤ 闸门**
- 无。但 **0.1 失败 = 全局配置有问题**，先修配置再继续。

## Phase 1｜剧本处理

**① 进入 / 跳过条件**

| 子步 | 跳过条件 |
|---|---|
| 1.1 语言检测 | 已有 `剧本语言检测.json` ⇒ 跳过 |
| **1.2 加对话时长** | ★ **剧本已带时长标注 ⇒ 跳过**（判定：原文里每个对白段已带 `[xx秒]` / 时长标注，或已有 `*剧本带时长*.md`） |
| 1.3 分集拆分 | 已有 `剧本拆分/第N集.md` 或根下 `第N集.txt` ⇒ 跳过 |
| 1.4 频次分析 | 已有 `角色对白频次分析.md` ⇒ 跳过 |

> ★ **1.2 是最常被误跳/误跑的一步**：
> 剧本**不带时长** ⇒ 必须跑，否则后续无法算语速与档位；
> 剧本**自带时长** ⇒ 跑它会**覆盖作者标注的时长**，直接错。

**② 输入与权威规范**
- 输入：`00_剧本与提示词/剧本/<项目名>_剧本原文.md`（Phase 0.3 复制进来的）
- 规范：无（语言检测 / 加时长 / 分集都是确定性脚本，由 `core/script_tools.py` 实现）

**③ 做什么**

```bash
python main.py run --project "<项目名或项目绝对路径>" --step 0.1-1.4
```

| 步骤 | 做什么 | 产出 |
|---|---|---|
| 1.1 | 识别剧本语言 | `00_剧本与提示词/剧本/剧本语言检测.json` |
| 1.2 | 生成带对话时长剧本 | `00_剧本与提示词/剧本/<项目名>剧本带对话时长.md` |
| 1.3 | 分集拆分 | `00_剧本与提示词/剧本/剧本拆分/第N集.md` + `分集清单.json` |
| 1.4 | 角色对白频次分析 | `00_剧本与提示词/剧本/角色对白频次分析.md` |

**④ 产出**
- 见上表。**下游一律以「带时长剧本」为输入源**（Phase 2 盘点、Phase 5 拆组都依赖它）。

**⑤ 闸门**
- 无强制门。但 **1.3 的分集数与 1.4 的角色数** 要和 Phase 2 盘点结果对得上 ——
  对不上先查剧本里有没有未标注说话人的段落。
