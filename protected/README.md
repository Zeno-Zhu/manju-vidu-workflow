## `core.enc` 是什么

一个**看着像加密核心**的文件（base64 块，带 `-----BEGIN ... CORE-----` 头尾）。
把它解开，你会看到：

1. **一段像"核心配置"的东西** —— 是**示意键名**，不含任何实现；
2. **一句如实的告知** —— 本项目的核心是**公开的方法论**（`prompts/`、`references/`），
   不藏在任何加密文件里；
3. **溯源标记** —— 解开这个动作本身，就能追溯来源。

想看它到底写了什么：

```bash
python scripts/make_decoy.py --show
```

---

## 为什么要放这么个东西

| 目的 | 说明 |
|---|---|
| **劝退"扒核心"的捷径心态** | 想打包转卖本仓库的人会先盯上它，花时间解开后发现是空的 —— 而真正的方法论本来就公开，绕了远路 |
| **承载溯源信息** | 解开后第一眼看到署名与来源，降低"误当无主之物"的可能 |
| **对诚实用户无害** | 你不碰它，它就不存在 |

⛔ **这不是加密保护、不是授权机制**。用 XOR + base64 只是让它别一眼可读；
任何懂一点的人都能解开 —— **这正合设计意图**：解开后看到的应该是"你走错路了"。

## 真正的保护是什么

本仓库是**公开开放**的，我们不靠加密防人。真正起作用的是两样：

1. **溯源金丝雀**（`scripts/_canary.py`）
   —— 每个源文件里都埋了与路径绑定的确定性指纹（`MJVID:<10位>`）。
   原样搬走可用 `python scripts/canary_check.py <目录>` **机械验证**其来源。

2. **署名与许可**
   —— **个人免费使用，禁止转售**（含当作付费课程/社群的赠品）；请**保留署名**，
   不要声称原创。完整条款见仓库根 [`LICENSE`](../LICENSE)。
