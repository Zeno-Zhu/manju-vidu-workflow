## 安装（两步，只做一次）

**① 拿到本仓库**

```bash
git clone https://github.com/Zeno-Zhu/manju-vidu-workflow.git
```

或在 GitHub 页面点 **Code → Download ZIP** 解压。

**② 双击 `1-初始化环境.cmd`**

它会自动：

- 找 Python（`py` → `python` → `python3`）；**没有就用 winget 帮你装**
- 装依赖（只有一个：`websocket-client`）
- 检查 Microsoft Edge
- 检查浏览器实例与登录态
- 在桌面创建「**Vidu 账号1 - 启动 / 关闭**」快捷方式

> 若提示「装完 Python 后本窗口看不到它」——**关掉重开再双击一次**即可（Windows PATH 的正常行为）。
> ⏱ 首次约 1–3 分钟；之后重跑秒过。

**③ 登录一次**：双击桌面「**Vidu 账号1 - 启动**」，在弹出的 Edge 里登录 Vidu 账号。
登录态存在**独立 profile** 里，以后不用再登。再跑一次 `1-初始化环境.cmd`，看到「环境全部就绪」即可。

**依赖**：Python 3.8+ ＋ `websocket-client` ＋ Microsoft Edge —— **不需要 Node**。

## 这是什么

一套**漫剧／剧情短视频的完整创作流程**，从剧本一直做到可交付的成片：

```
剧本 → 补时长/分集 → 资产盘点 → 生成角色/场景/道具图 → 分镜组规划
     → 写「自己人版」提示词 → 体检 → Vidu 出片 → 下载归档
```

- **渠道**：Vidu（**Token 直连，默认 CLI 模式**；网页自动化保留为兜底）
- **提示词**：只带**自己人**一套（镜头调度权交给模型，写"讲戏"式说明书）。
  自己人把中间镜头全交给模型，所以「首镜 / 末镜」必须写死 ——
  **同一套制式跨渠道复用时，边界只钉在两头**。
- **额度**：Vidu 有**每天 200 条闲时（不消耗积分）**，本包自带调度器帮你把额度跑满

## 关于「闲时额度」

Vidu 每天有 **200 条不消耗积分**的生成额度，但**同时进行中最多 100 条** ——
所以不能一口气把 200 条全推上去，得**掉一个补一个**。

本包自带调度器解决这件事：

```bash
# 建队列（只做一次，读作业单）
python scripts/vidu_queue.py init --jobs "<项目>/_vidu渠道/jobs_vidu.json"

# 看当前水位（进行中多少 / 今天用了多少 / 还能投几个）
python scripts/vidu_queue.py status --jobs "<项目>/_vidu渠道/jobs_vidu.json"

# 开始跑（它会自己盯着，掉下来就补投）
python scripts/vidu_queue.py run --jobs "<项目>/_vidu渠道/jobs_vidu.json"
```

> ⚠ 调度器默认按 **200/天** 算。如果你的账号今天已经跑过一些，先用 `status` 看看
> 「今日闲时」已用多少，把 `--daily` 设成"已用 + 想再跑的条数"。

## 常见问题

**Q：一定要用 Vidu 吗？**
本包只带 Vidu 一条渠道（就是为了好分发）。换成别的平台要另配。

**Q：闲时额度用完了怎么办？**
调度器会自动停手（到 200 条就不投了）。第二天额度刷新后重跑即可。

**Q：出片卡住 / 排障看哪？**
`references/vidu-平台机制.md` —— 里面记了所有实测坑（点击静默无效、上传被拦、翻页参数等）
和对应的排查方法。`SKILL.md` 最后一节「排障速查」也列了症状→位置对照。

**Q：我不想用命令行。**
不用。你只要跟 AI 说上面那些暗号，命令它会自己跑。

**Q：成片在哪？**
`<你的项目>/02_分集工程/EPxx/视频/`，按分镜组命名。

## 资产图不够？直接生成

用户手里没有的角色 / 场景 / 道具图，**直接用 Vidu 生成**（同平台、同一个登录态）：

```bash
# 文生图（角色设定板 / 场景 / 道具）
python scripts/vidu_image.py t2i --prompt "…" --model pro --ratio 16:9 --out "<项目>/01_资产库/图片"

# 参考图生图（拿基准图派生设定版、换姿势场景）
python scripts/vidu_image.py r2i --prompt "保持人物外貌与服装不变，…" \
                               --ref "<基准图>.png" --out "<项目>/01_资产库/图片"
```

- 模型：`fast`（全能 Image 2.5 Fast）/ **`pro`**（全能 Image 2.5 Pro）/ `base`
- ⏱ **一张约 2–3 分钟**；`--dry-run` 可先看会提交什么
- 配套的**四个资产提示词**都在 `prompts/`：角色基准图（9:16 竖版）、角色设定版（16:9）、场景设定版、道具设定版

> ⚠ 下载**只拿无水印版**（脚本已保证）：Vidu 返回两个地址，`watermarked.*` 是带"Vidu AI 生成"水印的，
> 我们只认 `download_uri` / `nomark_uri`。**别把水印版当成成品**。

## 它**不抢你的屏幕**

脚本驱动浏览器时，**Edge 窗口不会跳到前台、不会反复弹出来抢焦点** ——
你可以把窗口缩小放一边，同时继续用别的软件。

**怎么做到的**（不是靠"忍着"，是从根上取消）：

Chromium 会**节流后台/被遮挡的标签** —— 页面只渲染侧栏、页面里的请求永远 pending。
很多工具的做法是每次操作前把窗口**拽到前台**，那就是窗口老跳出来的原因。

本项目改为在**浏览器启动参数**层面取消节流：

```
--disable-features=CalculateNativeWinOcclusion   ← Windows 专用，最关键
--disable-backgrounding-occluded-windows
--disable-renderer-backgrounding
--disable-background-timer-throttling
```

再补一个 `Emulation.setFocusEmulationEnabled` 让页面"以为"有焦点（同样不抢窗口焦点）。

**实测**：把窗口最小化 4 秒后，页面内容完整、页面内的 API 请求照常返回 200。

## 资产管理：客户目录乱怎么办

客户拿来的项目目录**通常不是我们想要的样子** —— 标准目录旁边散着一堆
`护士三视图.png`、`人物定妆照/`、`故事板1.png`、`人物小传.docx` …

按类型与关键词**自动归位**到标准结构：

```bash
python scripts/organize_assets.py --project "<项目目录>"            # ★ 只出方案，不动文件
python scripts/organize_assets.py --project "<项目目录>" --apply     # 看清了才搬
```

**目标结构**：

```text
<项目>/
├── 00_剧本与提示词/剧本/       剧本 / 分集大纲 / 人物小传 / 设定
├── 00_剧本与提示词/EPxx/       分镜组表 / 制作规划 / 资产盘点 / 故事板
├── 01_资产库/用户上传/         ★ 用户给的原始件（原图留档，不覆盖）
├── 01_资产库/图片/             可用的角色/场景/道具图（语义名）
├── 01_资产库/音色/             音色参考
├── 02_分集工程/EPxx/视频/      成片
└── _出片记录/                  台账 / 日志
```

**三条铁律**：

| 铁律 | 说明 |
|---|---|
| ★ **只搬不删** | 永远不删用户文件；重名自动加 `_2`、`_3` |
| ★ **先方案后执行** | 默认 dry-run；看清方案再加 `--apply` |
| ★ **认不出就不动** | 猜不准的列进《待确认》，**不猜、不动** |

> 用户原图会**同时留一份**在 `01_资产库/用户上传/`（不覆盖、不"标准化"）。
> 详细规则 → `references/资产整理.md`

### 溯源机制

我们**不靠加密防人**，靠两样东西：

**① 溯源金丝雀** —— 每个源文件里都埋了与路径绑定的确定性指纹：

```bash
python scripts/canary_check.py .            # 自查：埋点是否齐全、指纹是否一致
python scripts/canary_check.py <别的目录>    # ★ 取证：判断代码是否源自本仓库
```

指纹是 `HMAC(密钥, 文件相对路径)` 的 10 位，**跨机器可复算 ⇒ 可作证**。
原样搬走的代码只要没逐行清理，`canary_check` 就能取出来。

**② `protected/` 诱饵** —— 一个看着像"加密核心"的 `core.enc`（解开是空的 ＋ 溯源信息），
用来劝退"扒核心拿去卖"的捷径心态。**它不参与任何授权校验**，正常使用完全不碰它。

## 用自己的提示词模板

本包**默认用「自己人」模板**。如果你有**自己一直在用的**提示词模板，可以替换：

1. 把你的模板文件丢进 **`prompts/_自定义模板/`**
2. 跟 AI 说一句「**用我的模板**」

AI 会先做一次**最小改造**给你过目 —— **只动三样**：

| 会改 | 不会改 |
|---|---|
| ① 每组的**分包标记**（改成 `&&start` … `&&end`） | 字段名 / 顺序 / 模块划分 |
| ② **资产引用写法**（统一成 `pn1,资产名=@`） | **正文怎么写**（你的写法原样保留） |
| ③ **开头四段**（补上【基础信息】【统一风格模块】【强制声明】【资产盘点】） | 剧情 / 台词（**一字不改**） |

> 判据：改造完，**你还认得出这是你的模板**。认不出就是改多了。
> 详细规则见 `prompts/_自定义模板/README.md`。
>
> ⚠ **注意**：自己人模板**不需要逐镜规划**（镜头交给模型），但**逐镜型的自定义模板需要**
> —— 换了模板后 AI 会自动回头调第 5 阶段的做法。

想换回来 ⇒ 说一句「**用回自己人**」。

### ★ 新增：出片进度一键盘点 `scripts/vidu_progress.py`

`vidu_tasks.py list` 每跑一个端口就会**覆盖** `~/.manju-vidu/tasks.json`
⇒ 多账号跑完只剩最后一个账号的台账，"全局还剩多少没生成"看不出来。
新工具按端口**逐个采集后合并**，一次给出四类计数 ＋ 失败原因：

```bash
python scripts/vidu_progress.py --jobs <项目>/00_剧本与提示词/视频提示词/jobs_vidu.json
#  ✅ 已出片 / ⏳ 队列中 / ❌ 失败（带 err_code）/ ⚠ 台账未对上
```

⚠ 若某个实例的窗口**被导航到了别的网站**（例：停在 `shengshu.feishu.cn`），
该账号会整批"消失"、表现为「已出片数突然变少 ＋ 一大批组查不到」——
在该端口**新开一个 Vidu 标签**即可恢复（`Target.createTarget`，不要劫持用户正在看的标签）。

### 本轮修掉的 5 个平台适配点（都已进代码）

| # | 症状 | 原因 / 修法 |
|---|---|---|
| 1 | 报「页面未挂载（bodyLen 太小）」整组放弃 | `body.innerText.length > 3000` 是**误报源**（实测恒 ~1100，页面其实好好的）⇒ 改为「有 file input 且（`.tiptap` 挂载 或 文本够长）」 |
| 2 | 音频上传 `点击后未收到 fileChooserOpened` | 点「音频」现在**先弹音色选择弹窗**，要**再点弹窗里的「上传音频」**，选完还要点「确认」 |
| 3 | 点「创作」没反应、零 POST | **首次提交会弹「声纹特征信息授权书」**，必须勾选＋点「已阅读并同意，继续创作」（每账号一次） |
| 4 | `ABORT_SETTINGS: 宽高比` | 宽高比下拉的**可选项量不到尺寸**（`height === 0`）⇒ 本剧统一 **16:9**（与 1792×1024 资产同画幅） |
| 5 | `ABORT_SETTINGS: 时长` | 时长轮播里「15」落在偏移窗口 `+460` 之外 ⇒ 窗口放宽到 `-120..1400` |

### 两条盘点纪律

- ★★ **`download --since` 用的是 UTC**：北京 13:00 = **`--since ...T05`**。
  传成北京时刻 ⇒ 整批判「台账里没有该组」，下载 0 条（`--dry-run` 一跑就能看出来）。
- ★★ **闲时额度必须先查再用**：`vidu_api.py quota` / `vidu_queue.py status` 都能读到权威值；
  分配提交任务时**按剩余额度比例分**，额度为 0 的账号先剔除，⛔ 不要平均分。
